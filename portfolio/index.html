How to verify the work

Open a project, inspect the source linked above, then inspect the exact workflow run and its commit. Run the documented tests in a suitable environment. A branch run does not prove the default branch contains that feature. A green build does not prove live deployment or independent review.

Evidence vocabulary: source present, static checked, simulation, CI executed, device tested, integration tested, production verified, and not verified. A status is meaningful only with a test scope and commit reference.

System relationships

Broccoli Core is the historical Android automation foundation. The extracted broccoli-rish repository isolates an Android shell transport contract. Grasshopper is a separate agent control plane. Helix handles cloud desktop/hypervisor infrastructure. OmniKali is a discovery/health pointer, not the workstation itself. These are related but should not be mistaken for a single verified production deployment.
